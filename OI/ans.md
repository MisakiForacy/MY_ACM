第14题
答案：C

解析：
这是经典的打家劫舍（House Robber）动态规划问题。

状态定义：`dp[i]` 表示考虑前 `i` 个房子（0-indexed）能获得的最大糖果数。

状态转移方程：
- 如果不偷第 `i` 家：最大值为 `dp[i-1]`
- 如果偷第 `i` 家：不能偷第 `i-1` 家，最大值为 `dp[i-2] + nums[i]`

因此：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

编程题1：选数

题目大意：
给定两个长度为 n 的数组 a 和 b。需要选择若干下标 p_1 < p_2 < \dots < p_k，满足间隔条件 p{i+1} \geq p_i + b{p_i}。目标是最大化选中下标对应的 a 值之和。

思路分析：
这是一道线性动态规划问题。

设 `f[i]` 表示考虑到第 `i` 个位置时，能获得的最大和（且第 `i` 个位置可选可不选，`f[i]` 更准确地说是"处理完前 i 个位置，且当前位于位置 i 时的最大累积值"）。

对于每个位置 i：
1. 选择 a[i]：则可以转移到位置 i + b[i]，更新 `f[i + b[i]] = max(f[i + b[i]], f[i] + a[i])`
2. 不选择 a[i]（或说跳过）：转移到下一个位置 i+1，更新 `f[i + 1] = max(f[i + 1], f[i])`

同时用 `ans` 记录过程中出现的最大值（因为不一定非要跳到最后，可能在某个位置结束）。

参考代码解析：

```cpp
for (int i = 1; i <= n; i++) {
    ans = max(ans, f[i] + a[i]);        // 尝试在当前位置结束，更新答案
    if (i + b[i] <= n)
        f[i + b[i]] = max(f[i + b[i]], f[i] + a[i]);  // 选择a[i]，跳到i+b[i]
    f[i + 1] = max(f[i + 1], f[i]);     // 不选a[i]，跳到下一个位置
}
```

时间复杂度： O(n)

空间复杂度： O(n)

编程题2：完全二叉树

题目大意：
给定一棵有根二叉树，求其所有子树中，有多少棵是完全二叉树。

思路分析：
使用 DFS 后序遍历，对每个节点 u 维护三个信息：
1. `chk[u]`：以 u 为根的子树是否是完全二叉树（1表示是，0表示否）
2. `mn[u]`：以 u 为根的子树中，从 u 到最近叶子的距离（最小深度）
3. `mx[u]`：以 u 为根的子树中，从 u 到最远叶子的距离（最大深度）

完全二叉树的判定条件：
1. 左右子树都是完全二叉树：`chk[u] &= chk[l[u]] & chk[r[u]]`
2. 左子树深度 ≥ 右子树深度：`mn[l[u]] >= mx[r[u]]`（保证最后一层节点靠左填充）
3. 最大深度与最小深度之差不超过1：`mn[u] >= mx[u] - 1`

其中空节点（下标0）需要特殊处理：`mn[0]` 应设为一个极大值（或按代码逻辑，在递归返回后参与计算）。

参考代码解析：

```cpp
void dfs(int u) {
    chk[u] = 1;                    // 初始假设是完全二叉树
    if (!u) return;                // 空节点直接返回
    dfs(l[u]);                     // 递归左子树
    dfs(r[u]);                     // 递归右子树
    
    // 条件1：左右子树都必须是完全二叉树
    chk[u] &= chk[l[u]] & chk[r[u]];
    
    // 计算当前子树的最小和最大深度
    mn[u] = 1 + min(mn[l[u]], mn[r[u]]);
    mx[u] = 1 + max(mx[l[u]], mx[r[u]]);
    
    // 条件2：左子树最小深度 >= 右子树最大深度
    // 保证右子树高度不超过左子树，且最后一层从左填充
    chk[u] &= mn[l[u]] >= mx[r[u]];
    
    // 条件3：当前子树最大深度与最小深度之差不超过1
    chk[u] &= mn[u] >= mx[u] - 1;
    
    ans += chk[u];                 // 如果是完全二叉树，答案加1
}
```

注意： 代码中 `mn[0]` 和 `mx[0]` 需要在主函数中初始化。通常 `mn[0]` 设为一个很大的数（如 `0x3f3f3f3f`），`mx[0]` 设为0，这样 `1 + min(mn[l], mn[r])` 对空节点不影响。

时间复杂度： O(n)

空间复杂度： O(n)（递归栈空间）
